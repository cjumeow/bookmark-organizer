# An example folder taxonomy

A starting point for grouping a mixed set of bookmarks, not a template to fill. Use only the folders the person's
bookmarks need, with at least three bookmarks each; merge or rename them to fit what the person actually keeps, and in
the person's language. A developer's tree might need `Programming` split in two and no `Shopping` at all.

| Folder | What goes in it | Split it into, when it passes about twenty |
|---|---|---|
| `Programming` | documentation, references, tools and courses for writing code | `Docs`, `Tools`, `Learning` |
| `Design` | fonts, colors, icons, images, design tools and inspiration | `Fonts`, `Icons`, `Inspiration` |
| `Work` | the person's own job: their team's wiki, dashboards, internal tools | by project or team |
| `Reading` | articles, essays, papers and talks to read or watch | `Articles`, `Papers`, `Talks` |
| `News` | news sites and newsletters read regularly | by topic |
| `Learning` | courses and tutorials on subjects other than programming | by subject |
| `Cooking` | recipes, cooking techniques, food sites | `Recipes`, `Baking`, `Techniques` |
| `Shopping` | shops, wish lists, price trackers | by kind of shop |
| `Finance` | banking, budgeting, taxes, investments | — |
| `Travel` | maps, trips, transport, bookings | by trip |
| `Health` | fitness, gyms, medical services | — |
| `Home` | home, garden, repairs, utilities | — |
| `Entertainment` | video, music, games, hobbies | by hobby |
| `Assorted` | the catch-all folder: whatever fits nowhere else | — (a theme that grows in it becomes a folder) |

Two habits make a taxonomy work better than any list of names:

- **File by what the person uses the bookmark for, not by what the site is.** A recipe video belongs in `Cooking`,
  not in a `Video` folder; a paper the person reads for work can go in `Work`.
- **Prefer fewer, broader folders.** Five folders of eight beat fifteen of two. When two small groups are close
  (`News` with two bookmarks, `Reading` with four), merge them rather than keep both.

Examples of names in the `Name: short description` form, for made-up sites:

| Folder | Bookmark |
|---|---|
| `Programming` | `Ferrite: API reference`, `Codepad: run code in the browser`, `Querylab: SQL course` |
| `Design` | `Typeshelf: open-source fonts`, `Tintbox: color palette generator`, `Glyphkit: outline icons` |
| `Cooking` | `Stovetop: weeknight recipes`, `Stovetop: chickpea curry`, `Levain: bread baking guide` |
| `Assorted` | `Rainwatch: hourly forecast`, `Pathfinder: mountain hiking routes` |
